# SFW 对齐 SFM：整体审查

日期：2026-11-10  
目标：SFW（sing-box for Windows）应在配置语义、核心功能、状态可信度和交互流程上对齐本机 SFM；Apple 的系统扩展、菜单栏等采用 Windows 对应实现。当前版本尚不具备完整功能等价性，不能标记为「完全对齐」。

## 审查证据与边界

本轮直接检查本机 SFM 的策略组、配置编辑/列表、连接详情、Tailscale 实时状态与设备列表，以及应用和隧道设置。对 Windows 端逐项审查后端 API、原生页面、生命周期、配置存储和构建流程，并运行专项测试。旧的 sfm-feature-spec.md 是 SFM 能力清单，其中的勾选并非 SFW 验收结果。

Windows 端本轮不具备完整远程 GUI 驱动能力；原生构建及 API 测试通过不等于逐个对话框和托盘菜单都已人工验收。整机重启、休眠唤醒、网络切换、管理员/TUN 场景尚未完成验收。

## 本轮发现并修正的实际逻辑问题

| 原差异/缺陷 | 修正 |
|---|---|
| 全部关闭连接按钮指向 501 未实现接口 | 实现关闭全部/单条连接的实际内核转发 |
| 连接行不能进入详情或关闭单条 | 增加详情对话框，显示地址、入站、进程、规则、链、流量、时间，并可关闭活动连接 |
| 清空日志只清旧缓冲，原生 UI 读另一缓冲 | 同时清理两份缓冲，重置暂停状态与显示 |
| 切换到损坏配置会丢失原运行状态 | 事务式切换，失败恢复原配置和服务 |
| 用户手动关闭系统代理后，重启/切配置会再次开启 | 保留原代理开关状态；明确启动仍按自动代理偏好执行 |
| 注入 Clash 控制接口时覆盖整个配置段 | 只覆盖本机控制地址和密钥，保留订阅声明的 default_mode 等字段 |
| 节点长列表、无折叠、仅全局测速、每秒整页重建 | 增加节点网格、每组测速、右键单节点测速、折叠状态保存；结构不变时只更新延迟 |
| 运行模式只显示、不支持配置允许的模式切换 | 读取真实 mode-list，多模式配置显示模式卡；不向单模式配置虚构 global/direct 选项 |
| 新建只能填写订阅 URL | 增加 JSON 文件导入、粘贴 JSON/手动创建，仍走内核解析校验 |
| 本地/远程类型可通过清空 URL 意外转换 | 与 SFM 一致，元数据编辑不更改类型；远程 URL 不可清空 |
| 新远程配置未默认启用 60 分钟自动更新 | 新导入远程配置启用每份配置的 60 分钟更新；已有显式偏好保持 |
| Tailscale 依赖缓存文件推断注册状态 | 接入内核 SubscribeTailscaleStatus，显示实时后端状态、本机和设备列表 |
| 退出节点缺少真实控制入口 | 基于实时可用退出节点列表提供选择/清除，后端校验目标；本轮不更改用户退出节点 |
| 出站计数错误地累加策略链长度 | 接入内核 ConnectionManager.Count，与 SFM 使用同一类计数；内存读取同源 memory.Total |
| 后端退出后 UI 一直访问旧 API 地址 | 状态请求失败后重新探测 runtime/恢复后端连接，不重放写操作 |
| 默认深色/自定义卡片和布局与 SFM 不同 | 本轮仅修可信状态与关键流程，细节仍列入差异，未宣称视觉等价 |

## 剩余差距与优先级

P0 = 缺少即无法实现核心产品目标；P1 = 主要日常能力；P2 = 外观/便利和特定平台映射。

| 优先级 | 能力 | SFM 基准 | SFW 当前状态 / 下一步验收 |
|---|---|---|---|
| P0 | TUN 流量接管 | PacketTunnel，覆盖不遵循系统代理的流量 | **未实现**；当前明确过滤 TUN 入站。需要 Windows 驱动、管理员/服务权限、路由与 DNS 接管、停服和异常退出恢复 |
| P0 | TUN 与 Tailscale 路由并存 | 隧道、端点与规则一体工作 | 未完成 Windows 全流量/Tailscale/LAN 并存验收；HTTP 代理能通不能代替该项 |
| P1 | DNS 与路由覆盖 | 隧道设置、默认路由与局域网排除 | 配置 DNS/route 透传，但 TUN 覆盖和相关开关不可用 |
| P1 | 登录/重启/休眠/换网恢复 | 系统隧道管理与按需规则 | 有登录自启、后台托盘、进程 API 重新连接；尚未完成整机/休眠/换网故障注入测试 |
| P1 | 配置更新的获取路径 | 核心远程配置实现、每配置更新 | 有按分钟自动更新；代理不可用/订阅受限网络、ETag/User-Agent、离线失败重试仍需对齐 |
| P1 | 配置分享与格式 | URL QR、QRS、BPF、JSON 文件 | 目前仅 URL 导入、JSON 文件/粘贴导入与 JSON 导出；QR/QRS/BPF 未实现 |
| P1 | 标准深链/文件关联 | sing-box URL scheme、BPF 文档 | 目前主要是 singboxwin 自定义 scheme；标准兼容/文件关联未完整实现 |
| P1 | 配置排序与命名 | 列表拖拽、唯一名称 | 未实现拖拽排序和完整唯一命名策略 |
| P1 | 配置完整恢复 | 用户可管理配置，更新失败不破坏服务 | 自动回滚已实现；删除有本地副本，但没有一键恢复入口 |
| P1 | Tailscale 完整控制 | 状态、设备、登录、退出节点、文件、SSH | 实时状态/设备/退出节点已接入；登录 URL/QR、设备详情、Taildrop、SSH 流程未完整实现 |
| P1 | 多端点工具 | 针对每个已配置端点的工具页 | 配置枚举已接入，完整实时控制目前主要覆盖 Tailscale；其余类型需独立适配 |
| P1 | 网络诊断 | 网络质量、STUN | 当前 Google 连通性仅为代理 HTTP 检查；STUN 与网络质量未实现 |
| P1 | 应用/内核更新 | 稳定/测试通道、检查与更新 | 未实现完整更新检查、下载安装与失败回退 |
| P1 | 连接历史完整性 | 内核推送的活动/关闭连接 | 当前轮询并在 UI 维护关闭记录；离开页面或短连接期间可能遗漏，不等价于内核事件流 |
| P1 | 远程控制 | 可连接其他设备的控制端 | 尚未实现 |
| P2 | 仪表卡片 | 配对曲线、拖拽排序、隐藏/恢复 | 已有双列和隐藏/重置；缺拖拽顺序、各流量卡独立曲线与一致布局 |
| P2 | 组的折叠预览 | 点阵、选中高亮、协议/延迟 | 网格、协议、延迟、折叠已补；折叠点阵与图标/动画尚未一致 |
| P2 | 菜单栏/托盘速率 | 可配置实时速率显示 | 托盘常驻/启停/退出已实现，速率显示模式未完成 |
| P2 | 主题与导航 | 跟随系统、上下文导航与系统图标 | Windows 仍有额外主题选项、部分导航/卡片可见性差异，需逐态截图对照 |
| P2 | 缓存、工作目录和报告 | 容量、清理、打开目录、崩溃/OOM/电源报告 | 尚未完整实现 |
| 平台映射 | 系统扩展/辅助服务 | macOS 机制 | Windows 应提供对应的受控提权、驱动/服务管理，不能照搬 Apple 文案或用空开关代替 |
| 平台映射 | iCloud / iPhone 导入 | Apple 平台特有 | 可使用 Windows 文件/云盘对应方案，明确平台能力，不伪装已实现 |

## 验收标准来源

整体对齐目标和验收规则已记录在项目规范 AGENTS.md，并由 CLAUDE.md 引用。本文是差异及验证证据清单；功能是否完成按真实内核行为、状态来源、异常恢复和相应场景验收，不以按钮存在或整体完成百分比判断。

## 本轮验证计划与记录

- 专项 Go 测试：连接 DELETE 转发、两份日志清理、真实内核 default_mode 保留、失败配置切换恢复、代理关闭状态保持、实时端点状态投影及停止取消订阅。
- 既有配置/路由测试：配置更新回滚、虚拟 GLOBAL 排除、真实 GLOBAL 保留、策略组顺序。
- Windows 原生 Release/x64 构建及 Go Windows 构建、Linux/Windows vet。
- Win11 实机检查实际版本、Rule 模式、两份真实策略组、端点实时状态、Google 代理连通。
- 未在用户会话中测试全部断开连接、退出节点切换或删除真实配置；这些写操作使用隔离测试/模拟内核控制端验证。

### Win11 本轮实测结果

- 版本 0.6.0，服务 running=true，系统代理开启，错误字段为空。
- 内核返回 Rule，10 条路由规则，available_modes 仅 Rule，因此不展示多模式切换卡。
- Tailscale 来源 live、状态 Running，初次采样显示 7 个对端，无需登录；重启后对端列表可能先为空，再随网络同步更新。
- 入站与出站分别从流量连接表和核心 ConnectionManager 获取，不再累加策略链长度。
- 临时配置的编辑、自动更新参数、订阅下载、无效 JSON 拒绝、删除备份测试通过，真实当前配置保持。
- 手动关闭系统代理后重启核心，服务恢复且代理仍关闭；测试结束恢复用户原来的代理开启状态。
- 在原生 UI 存活时退出后台引擎，客户端于测试的 20 秒窗口内自动启动并连接新的后台进程，服务和系统代理恢复。此结果不替代网络切换/休眠验收。
- Google 代理检查返回 HTTP 204。
- 尚未通过远程 GUI 对所有新对话框逐项点击；退出节点修改、批量关闭真实用户连接和删除真实配置没有执行。
